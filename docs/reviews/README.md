# Code Review Records

구현 후 리뷰 결과를 보관하는 위치다.

## 운영 규칙

- 코드 구현이 포함된 작업은 구현·테스트·문서 갱신 후 리뷰를 진행한다.
- Codex 리뷰는 변경 범위에 맞춰 백엔드, 프론트엔드, QA·테스트, DevOps 관점 중 필요한 조합으로 수행한다.
- Claude Code 리뷰는 지정 세션 `핀테크-클로드-리뷰`에 요청한다.
- 리뷰 결과는 `수용`, `반박`, `후속 과제`로 분류한다.
- 수용 항목을 반영한 뒤 관련 테스트와 `scripts/check-dev-rules.sh`를 다시 실행한다.

## 파일명
